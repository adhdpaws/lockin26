# Lockin 2026

A goal-tracking app designed with a "Bento + Swiss" aesthetic to help you lock in on your 2026 objectives.

## Features

- **Swiss Design**: Minimalist, typography-focused interface.
- **Bento Grid Dashboard**: Modular view of your goals and progress.
- **Focus Mode**: Distraction-free timer with "Lock In" ritual.
- **War Room**: Community squads (Coming Soon).

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the app:
   ```bash
   npm start
   ```

## Tech Stack

- **Expo**: v51
- **Expo Router**: v3
- **NativeWind**: v4 (Tailwind CSS)
- **TypeScript**

## Project Structure

- `app/`: Expo Router pages
  - `(onboarding)`: Initial setup flow
  - `(tabs)`: Main dashboard and navigation
  - `(focus)`: Full-screen focus mode
- `components/`: Reusable UI components
